② 托底强度 头部300ETF净申购 / 沪深300流通市值（bp）

与上图十字准星、缩放联动
怎么看这张图：蓝色柱 = 单日净申购（占流通市值 bp），零轴上方=净申购、资金流入，下方=净赎回、资金流出；蓝色粗线 = 20 日累计净申购，它才是「托底强度」——柱子是脉冲，线是持续力度；橙线 = 沪深300 收盘（右轴，点），只作对照不参与计算。柱顶细小刻线 = 单日净申购超过历史 P95 的极端流入日（尖峰）。 读法看两者的同向/背离：20 日线抬升而指数不涨甚至下行 = 托而不举（有资金承接、但价格没起来）；20 日线抬升且指数同步上行 = 量价共振；20 日线走平或转负而指数仍在涨 = 承接减弱、上涨靠存量资金。柱子单日暴量多为被动资金再平衡 / 指数调整生效日，不代表主动看多。 口径提醒：季度之间的份额披露值是线性插值，所以季度内这条线是平滑斜率，只有季度末与官方快照日（上图绿色小点）才是真实逐日申赎，不要把平滑段当成真实资金行为。

字段含义单位口径 / 来源分级
自洽关系：由 net1（5 点三角窗平滑）累加反推 ratio，故 net20 = Σnet1(20日) = (ratio_t − ratio_t−20) × 100 严格成立（残差 < 0.01bp，仅小数舍入）； pct252 由 ratio 真实滚动计算，图上归一化至底部视觉带、真实读数见 Tooltip； 事件锚点只做时间定位，不参与任何数值生成。

核心公式

aum_t (亿元)  = Σ_k [ shares_k,t (亿份) × nav_k,t (元) ]
              shares：季度末取基金定期报告披露的期末总份额，季度间线性插值；
                      官方快照日直接取东财 f84（份）÷1e8，并用 f116÷f84 校准净值
mv_t  (亿元)  = f117 官方快照流通市值(元) ÷ 1e8 × ( hs300_t ÷ hs300_锚日 )
ratio_t (%)   = aum_t ÷ mv_t × 100
              ※ 分子(ETF净值)与分母(流通市值)同随指数变动，价格机械效应抵消，
                故占比变化主要刻画份额增减，而非涨跌带来的账面缩放
net1_t (bp)   = (ratio_t − ratio_t−1) × 100      再经 5 点三角窗 [1,2,3,2,1] 平滑
net20_t (bp)  = Σ(k=t−19..t) net1_k = (ratio_t − ratio_t−20) × 100      ← 严格自洽
pct252_t (%)  = #{ ratio_j ≤ ratio_t , j ∈ [t−251, t] } ÷ 窗口长度 × 100
背离判定      = 20日 Δratio ≥ 8bp 且 同期 Δhs300 ≤ −1.5%，连续 ≥ 8 个交易日  → 浅蓝色块
阶段标签      = 事件日前后 [−10, +20] 窗口实测 Δratio / Δ指数 / 单日净申购 P95 自动分类
z动量_t       = [Δ20 ratio_t − mean(Δ20 ratio, 滚动252日)] ÷ std(Δ20 ratio, 滚动252日)
动量金叉      = z(占比) 上穿 z(指数)；动量死叉 = 下穿
大节点过滤    = 交叉后 25 个交易日方向不回头 且 期间最大 |Δz| ≥ 1.2
              （原始交叉 34 次 → 过滤后约 2~3 次/年，只留趋势级切换）
信号回测      = 聚类后统计未来 20/60 日指数收益 vs 全样本基准；t = (μ_sig − μ_base) ÷ (σ_base ÷ √n)
              ※ 原始占比(%) 与指数(点) 量纲不同，视觉交叉由双轴缩放决定，是伪信号，不予标记
              ※ ▲红=金叉 / ▼绿=死叉 / ◆黄=占比高位(≥90分位) / ◆青=占比低位(≤10分位)，
                均为描述性状态，非见顶见底预测，不可据此择时
