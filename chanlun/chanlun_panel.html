🏷️ 标注说明（图例 · 颜色 · 术语）

  • K 线主图颜色（A 股口径）：暗红 = 涨， 暗绿 = 跌；蜡烛按前复权收盘/开盘着色，细线为当根最高最低。 蜡烛刻意压暗并降低不透明度，让笔 / 浪段 / 中枢 ZG·ZD 参考线 / A-B 连线与 S·B 编号、价位等文字标记成为视觉主体； 红涨绿跌口径不变，高亮红 / 高亮绿仅保留给买卖点圆点与分型三角。 主图由本页依引擎 ind.bars 自绘，不改动站内公式。
  • 结构图层：橙色粗线 = 笔（boxwm.bi）、 紫色折线 = 浪型 ZIG 浪段（boxwm.wl）、 蓝虚线 = 中枢 / 箱体 ZG-ZD 水平参考线（boxwm.zs 或 box.top/bot）；箱体填充暂未绘制、 紫色虚线框 = A / B 背驰比较段、红绿圆点 = 引擎真实买卖点（sigs.chan，悬停看类型）、 小三角 = 分型。字段为空时如实显示「当前窗口无中枢 / 无箱体区间」，不编造结构。
  • 浪型 S1 / S2 / S3 … 与 B1 / B2 / B3 …：琥珀 = 浪顶 S、 浅蓝 = 浪底 B。编号由 boxwm.wl 的浪段端点去重、按时间排序后各自独立顺序编号；编号旁的小数字是引擎给出的真实拐点价， 悬停可看日期、当日收盘与 K 线序号，图表抬头给出浪段数与 S / B 数量。 关键口径：S1 / B2 / B3 等只是「本窗口内第 N 个浪顶 / 浪底」的浪序编号，不是缠论一买二买三买 / 一卖二卖三卖的分级； sigs.chan 的真实买卖点另以红绿圆点表示（不再重复编号，避免两套 S/B 混淆）。 浪段与拐点价均来自站内引擎输出，本页不重算、不补浪、不预测；AS-OF 截断时未来拐点不显示。
  • 副图（主图下方两栏常驻）：MACD (12,26,9) 柱 + DIF / DEA 线（引擎 series.MACD/DIF/DEA）、 成交量柱（红涨绿跌，与主图蜡烛同步压暗）。两栏可由上方「图层」勾选独立关闭。 背驰 A / B：紫色虚线框标出 A / B 比较段区间、徽章与连线同时画在 MACD 副图与下方 SkDJ 副图上（MACD 口径 = 段内 |MACD 柱| 峰值，SkDJ 口径 = 段内 |K − 50| 最大值），右侧证据面板同步给出「MACD 峰值」一行。
  • 裸 K 线图下方副图：SkDJ (9,3) 慢速随机（K / D 双线 + 20/80 超买卖 + 50 中轴，本页自算 RSV→SMA）、 CCI (14) 商品通道（CCI 线 + ±100 超买卖 + 0 轴，本页自算），二者跟随裸 K 线图的同窗口，可由上方「图层」勾选独立关闭。
  • ★擒妖量拉升（信号垂线）：琥珀色虚线贯穿主图 + MACD + 成交量两个副图， 钉住引擎 boxwm.tx 中 s=★擒妖量拉升 的 i 索引所指的那根 K 线；该 K 线下沿的 ▲ 是定位标记，主图顶部圆形编号按时间排序（分钟级信号密集时自动错行避免叠字）， 鼠标悬停垂线 / 三角 / 编号可看日期、收盘价与成交量。图表抬头显示命中次数与最近日期，导出 JSON 含完整清单。 编号只是序号，不是买卖点等级；标注来自站内混淆引擎，口径未公开，本页只做可视化，不重新计算、不筛选、不预测，也不构成信号确认。
  • MACD 副图上的 A / B 与背驰连线：紫色虚线框标出 A / B 两个比较段的区间； 圆形徽章 A / B 的高度 = 各段 |MACD 柱| 峰值（力度代理，与「MACD 面积 = |柱| 累计」同口径）； 徽章下方的小圆点是该柱实际柱顶（带符号）——若该段柱体全在零轴下方，小圆点会如实落在零轴下方，短竖虚线连接两者； 两徽章之间的紫色虚线是背驰比较连线，倾斜方向反映 A→B 力度变化；悬停可看数值与日期。 右侧证据表同步给出「MACD 峰值（|柱|）」一行，导出 JSON 含峰值 / 日期 / 带符号原值。连线只表示两段力度的相对比较，不是趋势线，也不是买卖信号。 同样的紫色虚线框 / A、B 徽章 / A→B 连线也同步移植到下方 SkDJ 副图（口径随指标换算为段内 |K − 50| 最大值，即偏离中轴的最远力度点，悬停看 K 值与日期），两处共用「背驰」图层开关。
  • 八门状态灯（与 K 线红绿无关，勿混淆）： 青 = 通过 / 已生效、 琥珀 = 警告（信息不足或未标注）、 红 = 缺失（引擎或数据未就绪）、 灰 = 未复核（需人工核对）。
  • 证据指标定义（均为自定义代理，非标准定义）：MACD 面积 = 区间内 |MACD| 绝对值累计； 价格力度 = 区间首尾收盘涨跌幅 %；SNR(dB) = 20·log10(|净价格变化| / 区间平均单根振幅)，仅作相对比较； 成交量力度 = 区间均量相对前置等长窗口均量的变化 %。A / B 取最近两段同向上涨线段（不足时用局部枢轴），可在图上核对。
  • 中枢：蓝色虚线标示 ZG（中枢高点）/ ZD（中枢低点）水平参考位，箱体填充暂未绘制；背驰：需点名 A / B 两个比较段与区间； 分型 / 笔：结构链的前两级。所有结构标注来自站内引擎的结构对象，口径为代理实现。
  • 术语：ZG / ZDZG = 中枢区间最高高点（中枢上沿），ZD = 中枢区间最低低点（中枢下沿）；二者之间的价格带即中枢（箱体）区间。本页以蓝色虚线水平标出 ZG / ZD 参考位并附价位，箱体填充暂不绘制（方案待定）。当引擎无严格中枢（boxwm.zs 为空）时，改取 box.top/bot 的箱体区间上 / 下轨作 ZG / ZD，并在横幅注明「仅箱体区间」。
  • 裸 K 线（页面下方独立区域）：明亮裸 K 线，叠加层全部按用户公式 boxwm.wl 移植、由本页依 ind.bars 自绘： 箱体（ZG-ZD，引擎 boxwm.zs/box.top/bot）； EMA9/10/11（EMA(C,173/193/213)）； VWAP（(VWAP_5+VWAP_13+VWAP_25+VWAP_43)/4 浅蓝点线）+ ZIG 转向上色（涨粉 #FF0080 / 跌绿 #9AFF02，依 ZIG(3,15) 斜率切换 VWAP 笔色）； 数字九转（TD 序列：下数绿/白、上数红/黄，C 与 4 日前收盘比较）； 高顶出货（PEAKBARS(3,15,1)<10 峰后窗口打卖出标记）； 趋势结构（黄=上升：两低点连线 + 两低之间最高点水平线 + 交点垂线；蓝=下降：两高点连线 + 两高之间低点水平线 + 交点垂线。分形半宽 N=5，低点统一取影线最低、高点统一取影线最高，只画最后一组；交点在未来时直接画在未来位置并标 T+n，仅作观察日历）。 说明：引擎 bars 无成交额字段，VWAP 用典型价(TP)成交量加权重建（×100 与 /100 抵消），为忠实近似而非真实成交额 VWAP；九转 / 高顶出货 标记置于对应 K 线上方（原公式锚定 HHV(H,43)·1.09/1.05 顶部，本页改为贴 K 线上方以避免出界）。
  • definition_mode本页固定 structure_proxy； approximation_loss与严格原著的差距； execution_allowed=false禁止执行； NO_ACTION不输出动作； as_of复核时点； 输入指纹FNV-1a 32bit（非加密哈希，仅比对同一输入）。
颜色歧义提醒：K 线区域「红 / 绿」只表示涨跌；右侧状态灯的「红 / 青 / 琥珀 / 灰」只表示复核状态。两者语义独立，不要互相套用。

📖 使用说明（先看这里）

  1. 选标的：下拉来自 ma_strategy_pool.json，与「盯盘参考」是同一份冻结快照；也可手输 6 位代码 / sh600000 / BK 板块代码后点「载入」。默认展示池内首只，仅作面板演示，不构成任何推荐。历史 K 线由外部行情源提供，源不可达时显示「数据缺失」。
  2. 选级别：日 / 周 / 月 / 60m / 30m / 15m（以站内引擎支持的周期为准）。级别一经选定，判定全部按该级别；切换级别或标的会重置人工复核状态与失效位。只改根数不打断复核。
  3. 看图层：用上方图层勾选控制分型 / 笔 / 浪型折线 / S/B 浪序 / 中枢 / 背驰 / 买卖点 / ★擒妖量拉升 / MACD / 成交量 / 箱体 / 裸图·SkDJ / 裸图·CCI / 裸图·EMA9-10-11 / 裸图·VWAP+ZIG / 裸图·九转 / 裸图·高顶出货 / 裸图·趋势结构。主图结构标注叠在 K 线上、主图副图两栏常驻；裸 K 线图叠加箱体 + EMA + VWAP+ZIG + 九转 + 高顶出货 + 趋势结构；裸图下方另有 SkDJ / CCI 两副图；关掉「S/B 浪序」只隐藏 S1/S2/S3 等编号与拐点价（浪型折线仍由「浪型折线」控制），关掉「★擒妖量拉升」会一并隐藏所有琥珀色虚线、三角与编号，拖 AS-OF 时只保留截至该时点的命中与拐点。
  4. 拖 AS-OF：时间轴按时间点截断并重绘，用于复盘历史某刻的可见信息。注意它只截断显示，不重算结构；回放按钮可自动推进，速度 1x / 2x / 4x。
  5. 核证据与八门：右侧「背驰证据」给 A / B 数值对比与 5 项门槛徽章；「八门自检」里「类型 / 比较 / 触发」三门需人工核对后点「标记通过」。任一门未过，横幅降级为「仅观察」。
  6. 先写失效点：在右侧填入失效位与失效条件，风险门才通过。顺序是先写失效点，再谈结论。
  7. 导出留档：「导出快照」生成自包含静态 HTML（含当前自绘 SVG），「JSON」导出纯证据数据。两者带 as_of / 定义口径 / 近似损失 / 输入指纹 / 失效条件 / 免责，不含账户、持仓、路径或凭据。
  8. 切回其他 Tab / 满屏：本面板是独立 iframe 子页，与「3D筹码」「盯盘参考」互不影响；点 ⛶ 可在新标签页满屏打开。
边界与禁止事项：仅供技术研究，不荐股、不给买卖指令、不承诺收益，不接券商、不下单。 选股池与 K 线缓存都是冻结快照，非盘中实时；数据取不到时显示「数据缺失」，绝不补零或用合成数据冒充行情。 八门全通过也只代表复核流程闭合，不代表结论正确，更不代表可以执行。
