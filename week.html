📖 名词解释（折价率 / 破发% / 锁定期 / 回补信号 / 定增类型 / A·B·C 分组）
定增价：向特定投资者发行股份的价格（发行价）。
较定增价%：蓝=破发（现价＜定增价） / 红=浮盈，沿用全站「负=蓝」体系。
折价率：发行价较前 20 个交易日均价的折扣（折价率 = (前20日均价 − 发行价) / 前20日均价 × 100%）。如「12.0~」=发行价约较前20日均价低 12%（非发行价仅为均价的 12%）。折价越高=安全垫越厚；2024 竞价定均 14.88%、2025 降至 12.7%。标注 ~ 为人工估算。
较定增价%（破发%）：现价较定增价的涨跌幅，是安全垫消耗程度的直接读数；表头与名词解释统一用「较定增价%」这一术语。
锁定期：1Y=一年期竞价（≤35 名机构，价高者得，锁 12 月）/ 3Y=三年期定价（实控人/战投，预案锁价，锁 36 月）。标准值为 12 / 36 月，实际存在 6 / 18 月等非标安排，按公告实际月数显示。
解禁日：限售股上市流通日（直接取自公告，非推算）；距解禁 ≤20 交易日为「解禁压制」窗口。带 * 为按锁定期推算。
回补信号：现价回升至较定增价 ≥−2% 且过去 20 个交易日内曾＜−2%（由前端按日 K 实时计算，拉取失败时回退种子宽松判定）；破发股最终回补概率历史达 95.14%、均 46 天。接近回补 = 较定增价 ∈ [−5%, −2%) 且过去 20 个交易日内曾 < −5%，为回补前的早期预警信号。
定增类型：类型维度是分档策略成立的前提——同为破发 −30%：项目融资类修复概率相对低（招商证券：一年期项目融资破发后不到一半能在解禁前修复价差）；资产重组类回补概率高达 95.14%、均约 46 天（华泰联合），深度破发档位博弈价值显著更高；大股东参与型（三年期）定价锁定 + 36 个月锁定期，解禁前维护股价动机强，「兜底博弈」逻辑与纯机构竞价型完全不同。标的名旁 * = 高回补博弈类型（资产重组类 / 大股东三年期·实控人），即破发后修复概率显著更高的标的。
资本结构分组：A=增净资产（项目融资/补流/引战）· B=资产证券化（重组/注入/整体上市/置换/融资收购）· C=配套融资。

设计底线：先用后复权口径 + 三层刚性剔除（ST / 连续两年亏损 / 重大违规）把雷排掉，再看机会；破发持续期、解禁预警、资金异动用客观数据替代主观判断。本板块是「半自动挖矿机」，只输出候选池与形态标签，开枪纪律由人执行。
① 重点盯左下角破发占比低、但已深跌，再叠加「低 PE + 底背离 + 主力净流入」，是优先观察的试错区。例：天有为 603202（11-05 快照：含权息 −38.04%、5 日主力 +1992 万）。
② 避开右下角长期深度破发 + 临近解禁 + 日均额枯竭，容易被闷杀，估值看着便宜也不碰。例：麦加芯彩 603062（破发占比 94.7%、3 天内首发解禁、20 日均额约 0.14 亿）。
③ 不猜底在哪破发股有下跌惯性。等「底背离 + 温和放量」出现、资金先进场后再分批建仓，不一次打满。
上述象限只是观察区间划分，不是胜率结论：池内未做持有期 / 卖出规则的胜率回测，所有标签均为统计描述，不构成买卖信号或投资建议。示例取自 2026-11-05 数据快照，每日收盘后重算，数值会变化。
v4 三个口径：①「同行相对 PR」是无量纲百分位（越小＝在同行业新股里越差）。同行破发率是家数占比、个股破发% 是价格幅度，量纲不同不可相减；样本 < 5 标灰且不参与筛选。② 底背离 / 温和放量标注「N 天前」（交易日），超过 10 日且涨幅 < 3% 灰化标「过期」，涨幅 ≥ 8% 标「已兑现」——只降级展示，不改入池。③ 风控列的业绩标签取最新报告期实际同比，好坏都标；业绩预告仅近 90 天内才算「近期催化」。④「四维共振」清单是观察入口，不是胜率结论或买卖信号。
v5 三个实战防御口径：①「尾盘拆分」把主力净额拆成早盘 / 午后 / 尾盘，尾盘占全天 > 50% 且当日上涨即标「尾盘偷袭疑似」（诱多，次日易低开），见表格新增「尾盘拆分」列。②「解禁股东精细化」区分创投 / 机构（市场化减持＝真雷）与国资 / 大股东 / 控股股东（减持意愿弱＝假雷），关键词推测、标「需人工确认」，见「解禁股东」列。③「板块联动」给出个股当日涨相对所属板块的偏离（正＝跑赢板块、非纯板块带动），见「板块联动」列。三项均为 fail-safe 降级标签，数据缺失时标「— / 待核 / 分时数据缺失」，不影响入池。

📖 口径、三层剔除规则与被剔名单（可审计）
基础池：近 3 年上市、沪深主板 / 创业板 / 科创板，剔北交所 / B股 / ST / *ST / 退市 / 风险警示。
复权：东财 push2his 后复权（fqt=2）为主源、腾讯 fqkline hfq 交叉校验；两源后复权均以上市首日为基准，发行价无需再复权。送转除权造成的「假破发」在 P0 层剔除。
L2 连续亏损：最近两个完整会计年度，归母净利与扣非净利孰低者连续为负 → 一票否决。
L3 重大违规：36 个月内财务造假类行政处罚 / 12 个月内立案未结案 / 最近年度否定或无法表示意见的审计意见 → 一票否决；警示函、问询函、会计差错等仅标记观察、不剔除。公告按上市日之后过滤，避免 IPO 审核问询函误杀。
动态维护：每日收盘后重算，入池判定只用收盘价；盘中实时价仅用于展示与估算。人工黑名单持久，自动判定每次重算，不落永久禁入。
破发持续期：上市以来逐日比较「后复权收盘价 < 发行价」，输出破发交易日占比、当前连续天数、最长连续段、首次破发在第几个交易日。名义（不复权）口径会被送转除权放大（如雪祺电气含权息 6 天 vs 名义 223 天），故主判据与散点图一律用含权息口径。
估值与解禁：当前 PE(TTM) 取东财按报告期估值表最新一期；TTM 净利转亏时 PE 为负、压缩比不适用（页面标「TTM亏损」）。「低PE错杀」= 发行PE < 30 + 深度破发 + 当前PE 未高于发行PE；当前PE > 发行PE 的 1.5 倍标「盈利下滑」。解禁取未来 3 个月明细，占比 ≥ 20% 标红。
行业破发率：该行业近 3 年新股中名义破发的比例，用于区分「行业系统性杀跌」与「个股问题」；不是行业景气度，样本数 < 5 会标注。申万营收增速中位数 / 库存周期无结构化数据源，暂不提供。
数据可靠性：K 线走东财分片域名池轮换，腾讯完整后复权序列可整源接管；盘中丢弃当日未完成 K 线；复权失败率 > 20% 或入池数较上期骤降 > 50% 时，生成器拒绝覆盖上一版产物。腾讯备源接管时，成交额按「成交量 × 单位换算 × 均价」估算（误差 < 2%）；单位按板块区分 —— 沪主板 / 深主板 / 创业板成交量以「手」计（×100），科创板 688 以「股」计（×1，早期版本误乘 100 已修正，并在 20 日均额异常超 20 亿时自动纠正）。换手率无可靠来源显示「—」并标「备源估算」。
解禁分类：底层解禁表无「解禁类型」字段，故用解禁日距上市月数区分 —— 12 个月＝首发原股东一年期、36 个月＝首发控股股东三年期（均为高危）、6 个月＝首发配售小额解禁。本池均为近 3 年新股，不存在定增解禁。散点图红点＝30 天内有解禁。
流动性与形态：20 日均成交额来自日线成交额取均值；破发段日均换手率取「当前连续破发段」；距最高点回撤 = 最新后复权收盘 / 上市以来最高后复权收盘 − 1。「僵尸股」＝破发段日均换手 < 1.5%；MACD 底背离＝近 60 日价格创新低而 MACD 柱未创新低；温和放量＝近 5 日均量 / 近 20 日均量在 1.2~2.5。这些都是形态描述，不是买卖信号。
资金流双源：优先逐股取近 5 日主力净额合计；逐股接口大面积失败时自动降级为全市场单日资金流快照（当日主力净额 + 现价相对主力 20 日成本偏离），页面标「单日」。降级只影响标签，不改变入池。冷门错杀股与高流动性本就互斥，故「日均额 ≥ 5000 万」只做成可切换筛选器，不作为入池硬门槛。
TTM 转亏预警：L2 只核对经审计年报，抓不到「上市后首个报告期 TTM 转亏」。当前 PE 为负的股票会标「TTM转亏 / TTM亏损」预警，仅提示人工复核，不硬剔。审计意见与证监会处罚仍无结构化数据源，需人工复核。
同行相对 PR（v4）：同行业近 3 年新股按名义涨跌幅排序，本股的名次 / 总数 × 100 得百分位 PR，越小表示相对同行越差。「同行破发率」是广度（家数占比），个股破发% 是幅度（价格百分比），两者量纲不同不可相减；实测近 3 年新股普遍上涨，同行涨跌幅中位数 +12.8%~+197.2%，直接相减会让池内 25 只全部落在大额负值、毫无区分度，故改用无量纲排名。行业环境按破发率分「浅破发 ≤25% / 中性 / 系统性杀跌 >50%」。同行基准取最新价快照、个股取 as_of 收盘（实测偏差 < 0.5pp，收盘后重算对齐）；样本 < 5 标灰且不参与筛选。PR 不是行业景气度。
信号保质期（v4）：底背离与温和放量各自逐日重放，取「当前连续成立段」的起始交易日，输出发生日、已过交易日数与信号后涨幅。超过 10 个交易日且涨幅 < 3% 标「过期」（灰化），涨幅 ≥ 8% 标「已兑现」，其余「有效」。两个信号分别标注、互不覆盖；只降级展示，绝不改变入池规则。统计卡「有效信号」「过期 / 已兑现」、「仅有效信号」筛选器与共振清单，一律按任一进攻信号口径（底背离或温和放量）；卡片里若主信号已过期、但另一信号仍在保质期，会显示实际命中的那个信号并悬浮说明两者状态。
业绩催化（v4）：主口径取最新报告期实际归母 / 营收同比（东财 RPT_LICO_FN_CPD，本池覆盖 25/25），标签好坏都输出：业绩双增 / 增收不增利 / 减收增利 / 业绩下滑 / 低基数暴增。归母同比 > 300% 视为低基数失真，不计双增。业绩预告（RPT_PUBLIC_OP_NEWPREDICT）仅在公告后 90 天内才标「近期」，且正面（预增/扭亏/略增/续盈）与负面（预减/首亏/略减）都标；分红方案（RPT_SHAREBONUS_DET）标「分红预案」或股息率 ≥ 3% 标「高股息」。实测 2026-11-06 池内近 90 天正面预告 0 只、三季报归母同比正 5 / 负 20，只标利好会误导。
四维共振清单（v4）：同行浅破发且 PR ≤ 20 + 含权息 ≤ −10% + 最新报告期归母与营收同比双正 + 有效信号且主力净流入，并排除 TTM 亏损 / 大额解禁 / 立案处罚。四维交集只是观察入口，池内从未做持有期与卖出规则的胜率回测，不是胜率结论或买卖信号；所有 v4 字段都不参与入池判定。
