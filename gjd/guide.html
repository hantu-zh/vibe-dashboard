③ 主图元素逐个说明

1单日净申购柱（脉冲）
当天国家队有没有出手、出手多重。亮蓝 = 净申购（零轴上方），暗蓝灰 = 净赎回（零轴下方）。柱子高 = 当日买入力度大；孤立的一根高柱只是脉冲，要看粗蓝线确认是否持续。
220 日累计净申购（粗蓝发光线）
这是「托底强度」本体：近 20 个交易日累计净申购。零轴上方且持续爬升 = 在持续买入；贴近零轴或下行 = 托底暂歇。发光处理让它在众多元素中一眼可辨。
3沪深300 收盘（橙线，右轴）＋ MA20（金色细线）
橙线 = 指数价格（读右轴，点数）。金色细线 = 20 日均线，只作趋势参考。核心观察：资金是否领先于价格——粗蓝线先涨、橙线还没涨，是典型的托底领先信号。
490% 分位基准线（红色虚线 Q90）
用样本内 20 日净申购的 90 分位数（当前样本 Q90 = 12.6bp）画的横线。粗蓝线突破 Q90 = 极强托底信号——历史上只有最凶的一成买入力度能到这个位置。
5浅红区间 = 强托底窗口
当 20 日累计连续 ≥10 天站上 Q90 时，对应区间整块铺浅红底。含义：这不是一日游，是成建制的持续托底期，历史上往往对应重要底部区域。
6浅蓝区间＋斜虚线 = 量价背离窗口
资金流入（粗蓝线上行）而指数却没创新高的区间。斜虚线直白呈现这种「托而不举」。两段信号同时出现要警惕：国家队在接盘，但市场自己还没起来。
7绿点 = 官方快报日 ＋ ① 序号 = 事件标注
绿点 = 当天有官方快报/ETF 异动公告，数据为官方口径。金色序号 = 历史大事件（政策表态 / 汇金买入 / 外部冲击），完整对照表在页面底部「ⓘ 事件图例」悬停展开，与主图 K 线页的事件竖线一一同步。
8紫线 = 两融净买入（右3轴，亿元）
杠杆资金对照器：北向已停止日度披露，改用两融净买入看市场杠杆钱是在进还是在撤。紫线（两融）与粗蓝线（国家队）同向 = 合力；反向 = 国家队在接杠杆抛压。

④ 副图元素（量能与有效性验证）

9紫蓝色成交量柱（氛围参考）
副图中的紫蓝色柱 = 沪深300 成交量（亿手）。暗紫 = 常量日，亮紫（高不透明度）= 突破 5 日均量的放量日。净申购柱出现放量日附近才更可信——「有量的净申购才是真金白银」。
10托底有效性柱（绿/红，白描边）
直接回答「托底到底有没有用」：绿柱 = 每 bp 买入换来了正收益（一举托起）；红柱 = 白花钱，买了指数还跌（托而不举）。白描边保证在紫色成交量背景上不被吃掉。图例「托底有效性↑ / ↓」可分别点击显隐。与亮紫放量柱同期出现 = 量价共振，信号等级最高。
11底部缩放滑块（dataZoom）
拖动滑块或直接在图上滚轮缩放 / 框选，可回看 2021 年以来的完整历史。顶部「3M / 6M / 1Y / 全部」按钮一键切换常用区间。
12右侧状态卡（悬停联动）
默认显示最新交易日（示例：+31.1 bp），并带状态章——如红色警示章「量升价跌·托而不举」，与图内信号口径完全一致。👆 悬停任何一天，卡片实时切换为那天的数值、状态与分位（标题变金色＋金色光晕 = 「历史冻结态」）；移出鼠标或点击图表空白处恢复最新日。分位 ≥90% 时进度条变金色辉光（极强买入），<10% 变红。

⑥ 指标口径（写给较真的你）

托底强度（bp）

托底强度（bp）托底强度(bp) = 头部4只300ETF单日净申购额(亿元) ÷ 沪深300流通市值(亿元) × 10000

1bp = 万分之一。净申购换算成相对市值的比例，才能跨年份、跨市值比较「出手力度」。

20 日累计（粗蓝线）

20 日累计净申购net20[i] = SUM(net1[i-19 .. i])　—— 滚动 20 日逐日求和

滚动 20 日（约一个月）求和，滤掉单日噪声，回答「是不是在持续托」。

90% 分位线（Q90）

90% 分位阈值Q90 = PERCENTILE(全部样本 net20, 0.90)　—— 当前样本 = 12.6 bp

静态阈值，随样本滚动更新。突破 = 历史前 10% 强度的买入力度。

资金弹性（托底有效性）

资金弹性（托底有效性）eff = 近20日沪深300涨跌幅(%) ÷ 20日累计净申购(bp)　—— 仅 net20 > 5bp 时计算，单位 %/bp

每 1bp 买入换来多少涨幅。正值（绿柱）= 一举托起；负值（红柱）= 托而不举。最新交易日若未来 20 日未满，自动回退用过去 20 日计算。

为什么用两融替代北向？

结论：北向资金已停止日度披露，改用两融净买入作为杠杆资金的代理指标。
北向自 2024 年起不再披露日度数据；两融净买入取自东财 RPTA_RZRQ_LSHJ 接口的 RZJME 字段（单位亿元），用来观察国家队买入与杠杆资金的同向/背离——紫线（两融）与粗蓝线（国家队）同向 = 合力，反向 = 国家队在接杠杆抛压。

⑦ 数据来源与上线方案（方案 A · 已确认）

数据项来源说明
净申购 / 官方快报天天基金 F10 / 净值 · 东财 push2 行情快照原有链路，不变

方案 A 做什么

改 gjd/fetch_real.py：在每日生成 gjd_data.json 时一并写入 vol（腾讯成交量）与 marginChg（两融净买入）两个字段； 浏览器端保持纯同源原则（不直连第三方行情），只读同源 json。 ✓ 若字段缺失（旧数据/抓取失败），副图成交量与紫线自动隐藏、主图正常展示——优雅降级，不会白屏。

替换范围（最小作用域）

只改 gjd/template.html 中 ②托底强度（chartB） 的渲染逻辑与样式； ①国家队持仓代理图（chartA）原样保留；KPI 卡、今日解读、数据字典、CSV 导出、离线回退状态机全部保留；chan_report.html 不动。 因每日 GitHub Actions 会用模板重新生成页面，必须改模板而非生成物，否则次日即被覆盖。

发布闸流程

本地 SSR 验证 → 用户提供 PAT（分段） → Git Data API 单文件推送（gjd/template.html + fetch_real.py） → 触发 Actions → curl checksum 核验 → 线上版本号递增；推送前线上现版已留本地备份，可随时回滚。
