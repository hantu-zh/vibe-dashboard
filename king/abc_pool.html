ABC 分级口径 为什么不是直接照抄完整公式

A 级完整定稿全达标：核心 4 条 + 近 3 月未超 E30×1.12 + F1 连涨 3 月 + M25&M30 连升 3 期。历史上多数季度 0 只，属“确认级”标记。
B 级核心 4 条 + 近 3 月未超 E30×1.20 + 现价仍在 30 月线上方且偏离 ≤30%（未远离成本线）。
C 级仅达核心 4 条门槛：满 36 根月线、EMA5>EMA25>EMA30、gspt5>REF(gspt5,1)、C<28。
F1 不用 ZIGZIG(3,N) 是未来函数，事后重绘会把“未来才知道的拐点”算进信号；F1 一律用「连涨 3 月」替代，ZIG 只旁观不判选。

优化演进 v1 → v5 每一版改了什么、被什么数据推翻

v15/25/30 月均线 + gspt5>0：初始量化，把「远期上过 0 轴 / 近期在 0 轴上」翻成阈值条件。
v2gspt5>REF(gspt5,1)：>0 描述的是“水位”，不是“资金动能偏多”。改成边际脉冲后修掉了静态偏置。
v3ZIG(3,10) 替代 F1：全市场 PIT（截断重算）检验后确认会重绘，full 口径的正 α 是假的，只保留作参考。
v4不复权口径：截图对账确认软件跑的是「月线·不复权」，bfq 的 MA/gspt5 逐分吻合；前复权会因分红重绘历史、老股甚至出现负价格。
v5连升条件评估 + 复权定稿：MA(C,20) 连升并不更好（见下），保留 EMA25/30 双线；选股 bfq、收益用后复权等价换算。

口径说明

1. 数据时效：行情取腾讯报价与不复权月线；月线只用到上一根已收盘月（当期未走完的月不计入），避免月内重绘。 2. 入选天数按上证指数真实交易日历累计，不是运行次数——漏跑也不会算错，漏跑天数会在控制台标红。 3. 剔除只发生在季度末；日更新里的「仍达标」只是预警，不触发剔除。 4. 亏损标注按「上一财政年年报 + 本财政年已披露季报」的归母净利润，任一期为负即标注；上年+本期=连亏，悬停可看各期金额（亿元）。只标注，不参与剔除。 5. 入池以来为不复权价格口径，含除权跳空，只作跟踪，不做绩效结论；绩效请用后复权或等价总收益换算。 6. 候选池为全 A（含北交所），不足 36 根月线的次新股按 BARSCOUNT(C)>36 排除；已退市股缺失会带来幸存者偏差。
