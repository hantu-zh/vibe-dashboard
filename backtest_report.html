方法论与相对旧版修正点

  • 主配置（宽退出带）：最长持有 T+10 交易日，触达 +8% 止盈 / -5% 止损即退出（避免被窄带"削平"真实盈亏分布）；对照保留旧窄带 T+5/+5%/-3%。
  • 入口价优先用推荐价，缺失则用信号日收盘价；全程收盘对收盘，不再混用盘中实时价（旧版 jl 用新浪实时 parts[3]）。
  • 扣除双边交易成本约 0.22%（佣金+卖出印花税0.1%+滑点），短周期下显著影响净胜率（旧版零成本）。
  • 抓不到行情 / 无代码的记录单独计入「跳过」，不计入分母（旧版 jack_learning 会把缺失价静默算成亏损，系统性压低胜率）。
  • 输出胜率、平均盈/亏、盈亏比、期望值、最大回撤，并按月拆分以观察市场状态敏感度（旧版无样本量/显著性保护）。
  • 最大回撤为等权口径：每笔信号固定 10% 仓位串行复利（旧版为全仓串行复利，负期望策略在长序列下权益必然衰减到趋近 0、回撤随之趋近 100%，该数字失去风险度量意义，已修正）；单笔仍受 +8% 止盈 / -5% 止损约束，单笔最大亏损约 -5.2%。
  • 表格颜色规范：胜率等百分比列用红/绿二元对比（红=过半=强、绿=不过半=弱，A股涨红跌绿直觉，50%为策略生死线）；期望值列用粉/黄/蓝三档（粉=正期望、黄=零、蓝=负期望），两套色系完全区分、同行不混；灰色=无数据。
  • 已过滤新闻类策略（xueqiu_7x24 / 市场深度解读）；strong.html / week.html 的独立信号源（威震天 / 益盟强买 / 强势股 / 盗火线 / 短线作战）以及首板/周线类独立信号源（四周新高 fourweek_newhigh / LST lst）和慢热板块（slowrise_stocks）已并入回测——威震天、短线作战、四周新高、LST 带多日历史，益盟强买/强势股/盗火线/慢热板块为发布日单日快照（样本量有限属正常，不做显著性夸大）。
  • 本版已将历史重命名造成的重复行合并到当前在跑的定时任务规范名（菠菜涨停战法→大力水手菠菜、资金净流入→高欣资金净流入、陈小群战法四步选股→陈小群战法、高欣-季度环比增长→高欣季度环比增长），并并入全部独立选股栏目，使回测总览覆盖站点「12 个每日定时任务 + 威震天/益盟强买/强势股/盗火线/短线作战/四周新高/LST/慢热板块」共 20 个策略；预测明日涨停 亦已纳入。
